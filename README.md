# 3 AFC listening test
* Test for just noticeable differences on critical stimuli
* Registration of the participant is followed by the listening test GUI.
* Real-time audio controlled by UI (Librosa, Tkinter).
* stimuli can be retriggered and be compared without any artifacts by applying fades (much better than simple sample playback).
* Responses are saved to Excel (Pandas).
* Binomial test results are reported back to the participant.
